# Barbería Camilo

Sitio web de la barbería con catálogo de servicios, carrito y solicitud de citas. La página pública está hecha con HTML, CSS y JavaScript, sin instalar dependencias.

## Ver el sitio

**[Abrir Barbería Camilo](https://camilo03-benavides15.github.io/barberia-camilo/)**

## Ejecutarlo en el computador

Abre `PROYECTO BARBERIA CAMILO/index.html` en el navegador. Las imágenes y las fuentes se cargan desde internet.

## Archivos del proyecto

- `PROYECTO BARBERIA CAMILO/index.html`: portada, servicios y carrito.
- `PROYECTO BARBERIA CAMILO/reserva.html`: datos y horario solicitado.
- `PROYECTO BARBERIA CAMILO/pago.html`: resumen del abono y métodos de prueba.
- `PROYECTO BARBERIA CAMILO/confirmacion.html`: simulación del abono y solicitud por WhatsApp.
- `PROYECTO BARBERIA CAMILO/css/`: estilos del sitio.
- `PROYECTO BARBERIA CAMILO/js/`: carrito y pasos de la reserva.

## Importante sobre las reservas

El pago está en modo de demostración: no se procesa ni verifica ningún abono. Nequi muestra un número ficticio; no envíes dinero. La confirmación de prueba solo permite revisar el recorrido y no confirma una cita real. Antes de aceptar pagos, conecta una pasarela segura y confirma la disponibilidad de los turnos.
